# File actions retain their host-specific completion boundaries

Desktop applies its safety filtering, handlers and clipboard helpers. Android can refuse blocked file types and uses host file/share facilities. iOS open/save delegates to sharing. Mobile Copy image is a share handoff. Missing bytes, cancelled choices and failed handlers do not establish external completion. MCP cached-byte reads are bounded to 5 MiB and validated local keys.
