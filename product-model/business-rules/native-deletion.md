# Native Delete distinguishes Trash moves from permanent local or remote removal

Ordinary native Delete normally moves mail to Trash; Drafts/Trash can expunge. MCP organize-trash always moves, including Drafts. Native local failed/sending entries remove optimistic transport state, not remote mail. MCP permanent deletion executes its approved exact selection.
